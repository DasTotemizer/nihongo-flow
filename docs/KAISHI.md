# Kaishi 1.5k

## Findings (checked 26 November 2026)

- Official repository: https://github.com/donkuri/kaishi (README links releases at
  https://github.com/donkuri/Kaishi/releases/).
- The README links the AnkiWeb listing https://ankiweb.net/shared/info/1196762551. The
  product spec mentions 1931115754; the README's link is used unless told otherwise.
- **The repository has no licence file**, and the README grants no redistribution
  permission. The deck is built from material from other Core decks, AJT Japanese audio and
  irasutoya images, each with their own terms.

## Approach

Without explicit permission, Nihongo Flow does **not** bundle, host or repackage Kaishi.

1. The Deck Library lists Kaishi 1.5k first, with full author credit (栗 / donkuri, Tyogin
   and the contributors named in the README) and a note that the licence is unspecified.
2. "Get Kaishi" opens the official GitHub releases page (or AnkiWeb) so the learner
   downloads the `.apkg` themselves.
3. The learner picks the downloaded file and the Anki import wizard handles everything
   else, preserving fields, furigana, pitch accent, audio and images.
4. If the official download is unavailable, the app says so. It never silently substitutes
   another deck.

If the authors grant permission later, a direct one-tap download from the official release
URL can be enabled, verifying the file before import.
